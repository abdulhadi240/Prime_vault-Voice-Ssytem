# Batch 2: Collapsible Sidebar + Premium Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a collapsible icon-only sidebar with animated transitions, move the theme toggle to the sidebar bottom, update the color palette for a premium look, add a sidebar gradient, and wrap the overview minutes stat in a styled pill.

**Architecture:** All changes are isolated to three files. `app/dashboard/layout.tsx` receives all sidebar behavior changes. `app/globals.css` receives all color token updates. `app/dashboard/overview/page.tsx` receives the pill wrapper. No new files, no new packages.

**Tech Stack:** Next.js 14, React 18, TypeScript, lucide-react (already installed), CSS transitions (no animation library)
